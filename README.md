# Graph Refactored Domain Adversarial Learning for Underwater Image Enhancement

This repository contains the implementation of our manuscript:

**“Graph Refactored Domain Adversarial Learning for Underwater Image Enhancement”**

The code will be made publicly available after acceptance of the paper.

---

## Overview

This project implements a graph-refactored domain-adversarial learning framework for underwater image enhancement. The proposed method operates in the latent feature space of an encoder–decoder network and uses graph-based refactoring to improve structural preservation across different underwater degradation conditions.

The dataset preparation pipeline generates degraded underwater images from reference images using predefined water-type degradation coefficients. The trained model can then be used to enhance degraded underwater images and evaluate performance across multiple water classes.

---

## Environment Setup

Create the required environment using the provided `env.yml` file:

```bash
conda env create -f env.yml
conda activate <environment_name>
```

Replace `<environment_name>` with the environment name specified in `env.yml`.

---

## Dataset Preparation

The dataset is prepared using the script:

```bash
python data_prep/prep.py
```

This script applies underwater degradation coefficients to the images in the reference folder and generates degraded images for each water class.

The clear/reference images are stored in:

```text
data_prep/ref_images/
```

After preparation, the degraded and reference images are organized in the `data/` directory.

---

## Dataset Structure

The prepared dataset contains six underwater degradation classes. Each class contains **890 images**.

The degraded images are stored in the `raw/` directory, while the corresponding reference images are stored in the `ref/` directory.

```text
data/
├── raw/
│   ├── 0/
│   ├── 1/
│   ├── 2/
│   ├── 3/
│   ├── 4/
│   └── 5/
├── ref/
│   ├── 0/
│   ├── 1/
│   ├── 2/
│   ├── 3/
│   ├── 4/
│   └── 5/
├── label_train.csv
└── label_test.csv
```

The files `label_train.csv` and `label_test.csv` define the training and testing image pairs used by the dataloader.

Each row follows the format:

```text
degraded_image_path,reference_image_path,water_class
```

Example:

```text
raw/0/type1_001.png,ref/0/type1_001.png,0
```

## Training

To train the proposed model, run:

```bash
python main.py
```

The training script loads the image pairs from `label_train.csv`, trains the graph-refactored domain-adversarial enhancement model, and saves the trained checkpoints.

---

## Inference

To run inference on the test set, use:

```bash
python test.py
```

The inference script loads the trained model and evaluates it on the image pairs specified in `label_test.csv`.

---

## Expected Inputs and Outputs

### Input

The model expects degraded underwater images from the `data/raw/` directory.

### Reference Images

The corresponding clean/reference images should be stored in the `data/ref/` directory.

### Output

Enhanced images and evaluation results are generated by `test.py`. The output directory can be configured inside the testing script.

---

## Dataset Notes

- The dataset contains six water classes indexed from `0` to `5`.
- Each water class contains **890 image pairs**.
- The `raw/` folder contains degraded underwater images.
- The `ref/` folder contains corresponding clear/reference images.
- The CSV files provide image-pair paths and water-class labels for training and testing.
